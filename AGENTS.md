# Project Rules

- Use TypeScript strict mode.
- Use Go for backend logic.
- Keep GraphQL resolvers thin.
- Business logic belongs in services.
- Agents should have one responsibility each.
- Validate all AI outputs.
- Use structured JSON responses.
- Add tests for business logic.
- Keep agent execution observable.
- Prefer small composable functions.
- Do not hardcode secrets.
- Build one polished vertical flow before adding broad surface area.
- Avoid Kubernetes, Kafka, microservices, Terraform, and distributed infrastructure for the MVP.
